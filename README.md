# Comece pelo guia HTML

Autoria da metodologia e da documentação da distro: **Felipe Cruz de Melo**.

Versão 1.2 • 28 de outubro de 2026

1. Abra ABRA_AQUI.html no navegador para ver o passo a passo simples.
2. Anexe o ZIP a uma IA que leia arquivos e gere imagens. Escreva: “Use esta distro e me conduza, uma etapa por vez, para criar meu avatar”.
3. Se ela não abrir ZIP, extraia a pasta e anexe INICIAR_AVATAR.md separado.
4. Responda, envie as fotos solicitadas e aprove as propostas. A IA preenche os registros e escolhe as operações.

Você não precisa preencher fichas, escolher prompts ou programar para começar. Para a IA rodar scripts pela conversa, ela precisa executar código. O arquivo da distro não adiciona ferramentas ausentes.

## Conteúdo

- INICIAR_AVATAR.md: protocolo de condução por etapas.
- ABRA_AQUI.html: guia simples para a pessoa que vai criar o avatar.
- docs/REFERENCIA_TECNICA.html: método completo para consulta.
- prompts e modelos: apoio de produção e registros preenchidos pela IA.
- tools e testes: operações técnicas e verificações.

O método serve a qualquer gênero e idade representada, conforme referências e escolhas do usuário. Não impõe um modelo masculino adulto.

A IA avalia as fotos antes de gerar. Trocar só cor usa máscaras e código; mudar o modelo da roupa ou criar um acessório exige arte própria. O guia explica cada situação em linguagem simples.

## Módulo de imagem integralmente incluído

A pasta skills/avatar-imagens contém a skill completa com geração, edição por texto, resize e resample, código, dependências, diagnóstico e testes. A fonte integral do módulo imagegen do provedor também está incluída, com licença e referências. Não é preciso buscar uma skill externa. O motor generativo continua sendo o da IA ou uma API autorizada; modelos, contas e credenciais não estão dentro do ZIP.
